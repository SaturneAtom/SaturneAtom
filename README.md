# Mathieu Vialatte

Freelance AI Engineer based in France. I build LLM agents, multi-agent systems and RAG pipelines, and I stay on the project until they run in production.

Most of my work happens after the demo: evaluation on real data, regression tests, inference cost, and making an agent's answer traceable back to its sources.

## What I work on

- **Agents and multi-agent systems** — LangGraph, tool use, orchestration, human validation steps
- **RAG** — ingestion, chunking, retrieval, evaluation
- **Inference and cost** — self-hosted models (vLLM, llama.cpp), quantization, serverless GPU, model routing
- **Cloud** — AWS (Bedrock, ECS, Lambda, SQS) and Azure
